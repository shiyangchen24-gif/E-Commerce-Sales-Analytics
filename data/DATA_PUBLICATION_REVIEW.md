## 初步結果

|---|---|---|
| CSV 大小 | 40,500 筆 × 12 欄 | 不影響授權判斷 |
| 姓名／電話／電子郵件／完整地址 | 未發現欄位 | 不代表無重識別風險 |
| `Customer Id` | 有；能跨筆連結 | 檢查真實性及是否允許公開 |

| `Shipping Region` | 有；縣市層級 | 評估與其他欄位組合 |
| `Product Name`、金額、付款方式 | 有；交易細節 | 評估稀有交易與交叉識別 |
| 公開來源與許可 | **尚未核實** | 補來源網址、License 或書面授權 |
| 是否完全合成資料 | **尚未核實** | 向資料提供者確認 |
| 公開決定 | **暫緩原始 CSV** | 完成檢查後重新核准 |

## 最低公開門檻

- [ ] 具備資料集來源及允許公開再散布的可稽核證據
- [ ] 確認合法取得並允許放在公開 GitHub
- [ ] 確認資料是否完全合成，或已採用適當的去識別化措施
- [ ] 對跨訂單客戶碼與細粒度欄位完成連結風險檢查
- [ ] 確認對原始資料及任何公開衍生資料的授權要求
- [ ] 經負責人核准後再發布（記錄審查人及日期）

## 保護措施

根目錄 `.gitignore` 排除 `data/*.csv` 等交易匯出檔；**這不代表任何已追蹤的 CSV 會被自動移除**。發布資料時必須由審查過的 Pull Request 明確新增，不能以 `git add -f` 略過審查。

> 注意：即使未公開原始 CSV，本儲存庫既有 Markdown 文件可能包含從該資料集推導的彙總統計。若確認來源對衍生發表亦有禁止條款，請一併重新評估目前已公開的文件。

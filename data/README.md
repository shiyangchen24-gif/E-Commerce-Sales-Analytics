# Data｜電商訂單資料公開管理

> 狀態：**原始 CSV 暫不公開**（授權及資料治理審查待完成）  
> 檢查日期：2026-11-09  
> 原始檔（本地）：`ecommerce_orders (antdata)_ecommerce_orders.csv`，40,500 列、12 欄。

## 為何本目錄沒有上傳原始 CSV？

本專案的 GitHub 儲存庫為 **Public**。原始資料中具有 `Customer Id`（跨訂單追蹤碼）、`Order Id`、秒級 `Order Time`、`Shipping Region`、商品與消費金額。雖然沒有姓名／Email／電話／完整地址，組合後仍可能產生關聯或重新識別風險。

目前沒有查到可以核實的來源授權或公開再散布許可。**不能因資料用於課程、可能是模擬資料或找不到個資，就直接認定允許公開。**

## 公開前必須完成

1. **來源與授權**：確認資料集提供者、原始下載頁、License（是否允許公開再散布與修改），或取得權利人書面同意；保留授權證據與引用方式。
2. **資料性質**：向提供者確認是否確實為完全合成資料，是否存在任何真實個人交易。
3. **個資風險**：審查 `Customer Id`、`Order Id`、精確時間及其他欄位組合；如需公開微觀資料，重新評估欄位刪除、泛化及剩餘風險。
4. **完整性／維護**：確認幣別、時間範圍、更新頻率與是否有刪除請求程序。
5. **核准紀錄**：由資料權利人或專案負責人確認可公開版本及用途，才由 Pull Request 加入資料。

## 暫行操作

- 原始 CSV 存在個人／受控環境，不推送至 Public GitHub，也不要放在 Issue、Discussion 或 Release。
- Tableau 可從本地 CSV 讀取；分享 `.twbx` 前須注意其可能**內嵌原始資料**。若公開，只分享不含敏感資料的視覺輸出或經核准的資料源。
- 若僅供公開示範，可另行建立**完全虛構、不取樣自原始列**的合成 CSV；必須明確命名 `synthetic`，不可冒稱原始交易資料。
- 原始資料或其衍生明細也可能受到使用條款限制；即使只發布彙總表，仍須先確認授權。
